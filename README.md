# Fixora - Smart Service Hub

Fixora is a mobile service marketplace app built with React Native, Node.js, Express.js and MongoDB.

## Features
- Customer, Provider and Admin roles
- User signup and login
- Service booking system
- Admin provider assignment
- Provider notifications
- Booking status management
- MongoDB database integration

## Tech Stack
- React Native / Expo
- Node.js
- Express.js
- MongoDB
- REST APIs

## Run Project

### Backend
cd backend
npm install
npm run dev

### Mobile App
cd mobile_app
npm install
npx expo start
